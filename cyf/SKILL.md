## 0. 核心问题

1. 如何用一套**简单、稳定、可追随市场**的系统实现稳定获利，而非追求秘籍或完美参数？
2. 如何把"只做一种形态"落地成可重复执行的**盈利模式**与**操作计划**？
3. 如何在趋势、震荡、下跌三种市道中都有可盈利的模式，且靠"核心可变"自适应？
4. 如何靠"约束"(放弃+纪律)在人和人的博弈中赚散漫者的钱？
5. 如何把卖点交给市场(被动中把握主动)，用"预期+应对"化解概率特征？

## 1. 底层假设（哲学根基）

- **交易哲学·市场因我而存在**：带着自己的规则与标准参与市场；市场没有永恒本质，只有"因缘聚合下的小规律"，故系统必须有"核心不同"的多组盈利模式。(P114-116)
- **市场根本特征是"概率"**：没有必然；归纳法总结的规律反面例子可能更多。→ 操作方式必须是"预期+应对"，应对手段是"暂出观察+贴身紧打"。(P156, P157)
- **市场永远正确 / 追随市场**："能撑住的才叫支撑，能挡住的才叫阻力"；我们只能做跟随者，"不敢为天下先"，落后市场一点点但不过多。(P157)
- **稳定获利十字决 = 简单 + 追随市场 + 一以贯之**（技术理念灵魂）。(P154)
- **操作理念 = 始终把握操作中的主动权**：选股圈定能力圈、只在临界点买入、在被动中把握主动卖出、看大做小。(P159-164)
- **交易系统有效的关键在"约束"**：放弃大多数突破(>60%失败)，圈定自己的操作情景反复实践。(P116)
- **交易三阶段**（P114-115）：①不得意勿忘形(用规则) → ②得意忘形(固化理念) → ③从心所欲不逾矩(心学内化)。第一阶段最重要，先有小资金翻番实践再正常资金。

## 3. 主线框架（系统全图，P117-125）

```
交易系统(技术) {
  理念: 交易哲学(市场因我而存在) → 系统理念(个性化/稳定获利) → 技术理念(简单/追随市场/一以贯之) → 操作理念(主动权)
  实操: 技术认知(1价2量3指标4分时) + 资金管理(风险/仓位) → 交易系统规则(多组盈利模式) + 交易三宝 + 实践操作
}
交易心理 = "心学"提升修养(与技术并驾齐驱)
核心唯一 = 以"买点"为核心；核心可变 = 买点规则随市而变；周边简单 = 其余固定
```

- **系统 = 多组盈利模式的集合**；不同模式"形不同而神相似"，都基于强势股回调形态；区别主要在买点不同。(P115)
- **基础规则4条**(P221-226)：①操作风格=保守型；②只做强势股回调形态；③只做趋势票/超短票；④只以交易图谱积累。
- **盈利模式构成**(P220, P228)：选股规则 + 买点规则 + 卖点规则 + 风控/仓位规则。精力主要放买点。

## 5. 规则集（条件→动作→参数→止损→失效）

### 5.1 市场状态判定〔通用〕
- **条件**：收盘后看大盘指数(上证/深成指/创业板)走势与 MA30/MA60。
- **动作**：得出"阶段性操作背景"+资金使用比例：主多(上升/震荡)→100%；中性(下跌中反弹)→50%；主空(下跌趋势)→0%。
- **参数**：以选股主线定指数(小盘题材看创业板指 MA30)。
- **止损/失效**：比例须相对稳定、每日评估；趋势初期难识别，不追求精确辨势，用均线机械区分即可。

### 5.2 形态规则·强势股回调〔通用/买点前置〕
- **条件**：股价经历一轮强势上涨后开始调整，且未破坏原上升趋势。
- **动作**：只在三类回调中找买点——①普通型(ABC/5浪、跌幅大)；②强势回撤型(回撤<第一波0.382、气势如虹，如一字板转T板)；③平台震荡型(时空等效震荡、庄控)。
- **参数**：两要素校验——强势(价不破起涨点、量无大量阴线；二波拉升快而有力) + 经典(揉搓线/星线/地量/双底/涨放跌缩等经典价量配合)。
- **止损/失效**：回调中价跌破第一波起涨点、或甩出大量大阴量 → 该形态失效，放弃。

### 5.3 量价规则〔通用〕
- **条件/动作**：
  - 上升波段整体放量、回调波段整体缩量，且不可有过多/过密阴量 → 健康，持有。(P247, P807)
  - 地量(如连续缩量小星线)出现在低位/蓄势区 → 变盘/跟踪信号。(P224, P194)
  - 放量滞涨(实体缩小但量未缩) → 异常征兆=预警K线。(P789)
  - 背离(价新高但MACD柱峰值背离)只是"趋势可能终止"的提示，非立即反转；放量可化解背离。(P210, P211)
- **参数**：以"上涨看支撑、下跌看阻力"为总原则；位置比K线本身更重要。
- **失效**：放量长阴终止上涨趋势(如三聚环保2016.9.13)→原方向结束。

### 5.4 指标规则〔通用/辅助〕
- **均线**：指示平均成本(水)、趋势方向/强度/持续性、心理支撑阻力。多头发散持仓、空头发散空仓、聚集观望。两线同向金叉有效。(P202)
- **MACD**：用0轴划多空；DIF画趋势线可领先判反转(比价格趋势线早)；二次翻红+柱刚发散=真突破(3浪)，柱过度发散后背离双峰=假突破(5浪)；0轴附近第一次金叉/平飞"火烧连营"=大行情前兆。(P205-209)
- **参数**：均线10/30/60，MACD 12/26/9(默认，不调参——共识才有意义)。
- **失效**：指标只是价格影子，不可直接做判断；盘整市中MACD无规律，仅趋势明确时用。
- **分时(4分时)**：非必需(系统不要求盯盘)；三大功能——认个股个性、辨关键K线成色、看重要位支撑阻力攻防。用于消除关键K线不确定因素。(P211-213)

### 5.5 买点规则〔买点 mode〕
- **条件**：个股属某盈利模式 + 处临界点(回调结束反身向上) + 三点共振(走势/热点/盘面同满足)。
- **动作**：保守型=右侧买入，在企稳K线出现、放量反身上攻时介入；先 1/2 试探仓验证临界点，再 1/2 主力仓。
- **参数**：盘中涨幅>3%不追；错过临界点简单放弃；看大做小(日线定大形态、60分钟定进出点)。
- **止损**：与买点相伴的初始止损位=回调结束点(回调最低点)；收盘跌破才确认破位；若盘中需即时止损，设在关键位下方给余量。
- **失效**：未企稳就买、或突破关键点后未按预期运作(利弗莫尔异常2)→放弃或转预警。

### 5.6 卖点规则〔卖点 mode〕
三个固定卖点(P235, P812)：
1. **形态完成点**：预期中的经典形态走完即走(如双头/双底完成)。
2. **形态失败点(含初始止损)**：证明判断错误必须止损；破初始止损位即执行。
3. **暂出观察点**：出现"千里之堤溃于蚁穴"的异常先出来看。
- **两步验证法**(P769, P789)：预警K线(第一天异常，如倒锤头/乌云盖顶/巨量十字星)只是"预警"；次日同方向确认(预警确认)才卖出。如中国中铁2014.12.31倒锤头=预警，次日阴线确认→卖出；中国建筑2016.8.18风险K线→次日确认。
- **动作逻辑**：暂出观察最先处置；出了后若形态构筑失败=第二个卖点(走人)，若形态完成=第一个卖点(走人)，都不属则"贴身紧打"次日买回。
- **参数(保守型卖出)**：昨天涨停今天未顺势冲高(最高<涨停价)=反常→暂出；上涨中破前波峰支撑=破支→暂出；盘中跌幅>-6%且收盘未拉回、影响趋势→卖出(后宽容度提高：趋势票若收盘拉回且未破坏趋势，仅作预警K线等次日确认)。(P796, P990, P967)
- **失效**：与预期不一致即暂出观察；绝不因希望而留守。

### 5.7 止损/止盈/仓位〔风控仓位 mode〕
- **初始止损**：=回调最低点；收盘价破位执行；盘中即时止损位设在关键位下给余量。(P114, P990)
- **绝对止损**：单笔亏损≥7% 无条件平仓(预埋单)。(P218)
- **50%原则**：到手盈利>10个点须尽量保住(让利润奔跑但锁利)。(P703)
- **趋势票仓位**：253(20%开+50%加+30%做T)。(P232)
- **超短票仓位**：全仓进出(日内可分批)。(P232)
- **资金比例**：主多100%/中性50%/主空0%(随大盘MA定)。(P235)
- **主动防御**：一次完整交易后利润转出一半，不再回流股市。(P218)
- **失效**：绝不以摊平亏损头寸；满仓冲动建仓违反"试探性建仓"。

## 6. 交易计划模板（交易三宝，P233-241，表5-3）

每晚**非交易时段**书面制订，次日严格照执行，杜绝随意操作。

```
【大势】阶段性操作背景：主多/中性/主空   资金比例：__%   盘面：热点/龙头动向
【持有票】(池内 v 标志)
  股票/性质(S超短/L趋势) | 预期 | 完整应对(S/L位、暂出观察/贴身紧打条件)
【跟踪票】(池内非 v)
  股票/性质 | 提示线 | 触发买点条件
【交易日志】(盘中随手记：经验教训 + 今日研究票)
```

- **复盘分析4步**：①记当日盈亏(绘资金曲线，周更)；②经验教训→交易图谱；③完整交易→TR-图谱；④分析大势(主空/主多/中性+资金比例)与盘面(热点/龙头)。
- **操作计划原则**：预期+完整应对；"执行操作计划，杜绝随意操作"；无计划不操作。(P239, P605)
- **看大做小**：日线分析位置/大形态，60分钟定临界点进出。

## 7. 案例与反例（P271-302，节选）

**成功案例**
- 中国中铁(趋势票)：2015.3.19涨停突破、上升趋势+价量配合→3.20买10.16；持有至5.6跌破横盘最低收盘卖20.76；设提示线22.35，6.5触及但调整价量差放弃。(P271-276)
- 嘉澳环保(超短票·强势缺口支撑)：2017.3.10跳空放量涨停触发关注，设提示线59.58；3.24触及+企稳K线→买59.88；4.12盘中跌幅>-6%但涨停收盘→卖103.50，盈71%。(P280-286)
- 赣锋锂业(超短票·连续三日价量齐增)：3.10涨停启动，3.14-27回调无大阴、量渐缩=健康，不卖；依热点+形态介入。(P286)

**反例/失败案例（P298-302，节选）**
- 长荣股份：5.27放量滞涨(实体缩小)=预警K线，与嘉澳环保大跌前无预警不同→卖出时机差异说明"两步验证"必要性。
- 通用失败模式：错过临界点追高(>3%追)、破支撑不止损心存希望、满仓冲动、在不属于自己盈利模式的票上随意操作、因悔恨滞留心头影响判断。

## 8. 误区（P156, P162, P418, P884-899）

- 追求秘籍/完美参数、在波浪等艰深理论空转 → 系统始终变动不成型。
- 迷信必然/肯定(市场是概率)；用归纳法忽略反面例子。
- 主观设定长线/短线(卖点由市场给)；落后市场太多丧失优势。
- 凭希望留守、不止损；摊平亏损头寸。
- 盘中随意追直线拉升("钓鱼线")；无操作计划操作。
- "空仓是大智慧"常是懒惰借口；追随市场者空仓只为等现金抓大机会。
- 知易行难：系统只是"未得意勿忘形"阶段产物，须小资金翻番实践磨炼。

## 9. 适用边界（趋势/震荡/下跌）

- **上升趋势/震荡(主多,100%)**：趋势票(253加仓)与超短票(全仓)均可；局部结构性机会多。
- **下跌中反弹(中性,50%)**：仅用一半资金参与反弹；超跌后双底等模式适用；严控仓位。
- **下跌趋势(主空,0%)**：原则上不操作；系统靠"增加盈利模式"追随市场，而非简单空仓逃避。
- **不适合**：期货/高杠杆(书以A股现货为基准)；不适合无纪律、不能日复一日复盘者；不适合追求一夜暴富者。
- **核心可变**：市场变了旧模式失效时，须生成新盈利模式，不僵化。

## 12. 实战判读 mode（端到端判读模板）

触发：用户给一只票(代码 + 当前走势/截图/K线)并要求"按系统判读/完整分析"时进入此 mode。它是 §5 各规则的串联执行，产出一份可复盘的报告。

### 判读流程（逐步执行，每步给依据与锚点）
1. 市道：看大盘 MA30/MA60 + 指数 → 主多/中性/主空 + 资金比例（§5.1, P235）。
2. 归类：趋势票 or 超短票？属哪类回调（普通型/强势回撤型/平台震荡型）？（§5.2, P222-224）
3. 两要素：强势（价不破起涨点、量无大量阴）？经典（揉搓线/星线/地量/双底/涨放跌缩）？（§5.2）
4. 临界点 + 三点共振：走势(技术形态)✓、热点(主流板块/龙头)✓、盘面(大盘/盘口)✓；放量大阳反身、盘中>3%不追（§5.5, P162/P228）。
5. 买点：保守型右侧，企稳K线放量反身介入；先 1/2 试探仓（§5.5）。
6. 风控：初始止损=回调最低点(收盘破位执行)；绝对止损7%预埋；仓位 253/全仓；提示线设关键价（§5.7, P218/P232）。
7. 计划 + 卖点：写操作计划(预期+完整应对)；标卖出三件套与两步验证触发条件（§5.6, §6）。

### 标准范例（嘉澳环保 603822 · 超短票·强势缺口支撑，P280-286）
