# BooktoUse

> Read books and use it. 把读过的书蒸馏成可被 AI Agent 直接调用的 skill。

这个仓库存放从书籍中提炼出来的**方法论 skill**，不是读书笔记，也不是原文摘录。目标是：读完一本书之后，产出一个装进 AI 就能立刻上岗的操作手册。

## 目录结构

```
BooktoUse/
└── cyf/                # 技能：简简单单做股票·技术分析交易系统
    └── SKILL.md        # 技能全文（front matter + 方法论正文）
```

每个子目录就是一个独立的 skill，目录名即 skill 名。

## 已收录

| Skill | 来源 | 适用市场 | 版本 |
|---|---|---|---|
| [`cyf`](cyf/SKILL.md) | 楚云风《交易系统的构建心得和运用技巧》(2017) | A股 | 1.0.1 |

## 安装

skill 目录需要放在 WorkBuddy 的 skills 目录下，**目录名必须和 front matter 里的 `name` 一致**。

**macOS / Linux**

```bash
cp -r cyf ~/.workbuddy/skills/
```

**Windows（PowerShell）**

```powershell
Copy-Item -Recurse cyf "$env:USERPROFILE\.workbuddy\skills\"
```

装好后新开一个会话即可调用；若当前会话仍识别不到，重开客户端一次。

## 使用

显式调用：

```
@skill:cyf 用系统判读一下 300750
```

也可以靠触发词自动命中：`买点`、`卖点`、`止损`、`仓位`、`强势股回调`、`三点共振`、`交易计划`、`复盘检查`、`趋势票`、`超短票` 等。

`cyf` 只有一个入口，内部按意图切换 mode，不需要记多个命令：

| 内部 mode | 你说什么 | 产出 |
|---|---|---|
| `研判` | 这只票怎么样 / 现在什么市道 | 市场状态 + 个股形态归类 |
| `买点` | 能不能买 / 买点到了吗 | 临界点、三点共振、介入方案 |
| `卖点` | 该卖了么 / 怎么卖 | 三个卖点 + 两步验证 |
| `风控仓位` | 止损 / 仓位 / 资金管理 | 初始止损位、253 规则、资金比例 |
| `计划` | 帮我做交易计划 | 预期 + 完整应对的操作计划表 |
| `复盘检查` | 检查我的交易 / 系统 | 交易三宝 + 检查表 |
| `概念` | 某个术语什么意思 | 术语词条 + 页码锚点 |
| `实战判读` | 用系统判读这只票 | 端到端判读报告 |

## 设计原则

1. **五段式规则**：每条规则都写成 `条件 → 动作 → 参数 → 止损 → 失效`，可执行、可校验、可回放，避免"看情况"这类无法落地的话。
2. **参数保留原值**：均线 10/30/60、MACD 12/26/9、7% 止损、253 仓位规则等均按原著保留，不做"优化"。
3. **不臆造原文**：原著全文不随仓库分发。本地若有该书 md，引用时按 `<!-- 第 N 页 -->` 锚点回指；本地没有，就只用方法论摘要，不编造原文措辞和页码。
